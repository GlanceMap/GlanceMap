# Sources externes du compagnon

Dernière révision : 2026-03-20

Ce fichier répertorie les sites et API tiers référencés par l’appli compagnon pour les téléchargements et imports lancés par l’utilisateur.

## 1) Sites de téléchargement de cartes (ouverts dans le navigateur)

1. OpenAndroMaps
   - https://www.openandromaps.org/en/downloads

2. Alternativas Libres
   - https://alternativaslibres.org/en/downloads-mf.php

3. BBBike Extract
   - https://extract.bbbike.org/?format=mapsforge-osm.zip

4. Vector City
   - https://vector.city/

5. Freizeitkarte
   - https://www.freizeitkarte-osm.de/android/en/index.html

6. OpenHiking
   - https://www.openhiking.eu/en/downloads/mapsforge-maps

## 2) Raccourci vers un site GPX

1. VisuGPX
   - https://www.visugpx.com/

## 3) API de refuges/POI utilisées directement par le compagnon

1. API bbox de Refuges.info
   - https://www.refuges.info/api/bbox

2. API de polygones de Refuges.info
   - https://www.refuges.info/api/polygones

3. Interpréteur Overpass API
   - https://overpass-api.de/api/interpreter

## 4) Téléchargements de données d’itinéraire

1. Segments de calcul BRouter
   - https://brouter.de/brouter/segments4/

## 5) Données d’altitude DEM

1. Tuiles DEM3 de Mapsforge
   - https://download.mapsforge.org/maps/dem/dem3

2. Mapzen Terrain Tiles / AWS skadi
   - https://s3.amazonaws.com/elevation-tiles-prod/skadi
