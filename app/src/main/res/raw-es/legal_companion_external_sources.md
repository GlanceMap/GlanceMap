# Fuentes externas de la app del teléfono

Última revisión: 2026-03-20

Este archivo enumera los sitios web y API de terceros que la app del teléfono utiliza para descargas e importaciones solicitadas por el usuario.

## 1) Sitios de descarga de mapas (se abren en el navegador)

1. OpenAndroMaps
   - https://www.openandromaps.org/en/downloads

2. Alternativas Libres
   - https://alternativaslibres.org/en/downloads-mf.php

3. BBBike Extract
   - https://extract.bbbike.org/?format=mapsforge-osm.zip

4. Vector City
   - https://vector.city/

5. Freizeitkarte
   - https://www.freizeitkarte-osm.de/android/en/index.html

6. OpenHiking
   - https://www.openhiking.eu/en/downloads/mapsforge-maps

## 2) Acceso directo a sitio GPX

1. VisuGPX
   - https://www.visugpx.com/

## 3) API de refugios y POI usadas directamente por la app del teléfono

1. API bbox de Refuges.info
   - https://www.refuges.info/api/bbox

2. API de polígonos de Refuges.info
   - https://www.refuges.info/api/polygones

3. Intérprete de Overpass API
   - https://overpass-api.de/api/interpreter

## 4) Descargas de datos de rutas

1. Segmentos de rutas de BRouter
   - https://brouter.de/brouter/segments4/

## 5) Datos de altitud DEM

1. Teselas DEM3 de Mapsforge
   - https://download.mapsforge.org/maps/dem/dem3

2. Mapzen Terrain Tiles / AWS skadi
   - https://s3.amazonaws.com/elevation-tiles-prod/skadi

## 6) Nota de transparencia

- Estas fuentes son externas a GlanceMap.
- Cada proveedor controla la disponibilidad y calidad de los archivos, la disponibilidad del servicio y sus condiciones legales.
- El usuario sigue siendo responsable de los derechos de redistribución de los archivos descargados externamente.
