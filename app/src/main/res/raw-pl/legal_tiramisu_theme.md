# Motyw Tiramisu

Ostatni przegląd: 2026-04-26

Ta informacja opisuje dołączony motyw renderowania Mapsforge Tiramisu używany przez GlanceMap.

## Dołączona zawartość

- Nazwa motywu:
  - `Tiramisu`
- Ścieżka dołączonego zasobu aplikacji:
  - `app/src/main/assets/theme/tiramisu/Tiramisu.xml`
- Dołączone drzewo zasobów:
  - `app/src/main/assets/theme/tiramisu/res/`

- Dołączone archiwum wydania:
  - `v4.4`

## Uwagi o działaniu motywu

- Tiramisu zawiera Mapsforge `stylemenu`.
- Domyślny dołączony styl to:
  - `tms_hiking`
- Widoczne wbudowane style to:
  - `Hiking`
  - `Mountain biking`
  - `Velo`
- XML zawiera `<hillshading zoom-min="9" zoom-max="17" />`, więc cieniowanie terenu jest uznawane w aplikacji za obsługiwane.
