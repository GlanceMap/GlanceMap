# Źródła zewnętrzne aplikacji towarzyszącej

Ostatni przegląd: 2026-03-20

Ten plik wymienia zewnętrzne strony i API, do których odwołuje się aplikacja towarzysząca przy pobieraniu i importowaniu inicjowanym przez użytkownika.

## 1) Strony pobierania map (otwierane w przeglądarce)

1. OpenAndroMaps
   - https://www.openandromaps.org/en/downloads

2. Alternativas Libres
   - https://alternativaslibres.org/en/downloads-mf.php

3. BBBike Extract
   - https://extract.bbbike.org/?format=mapsforge-osm.zip

4. Vector City
   - https://vector.city/

5. Freizeitkarte
   - https://www.freizeitkarte-osm.de/android/en/index.html

6. OpenHiking
   - https://www.openhiking.eu/en/downloads/mapsforge-maps

## 2) Skrót do strony GPX

1. VisuGPX
   - https://www.visugpx.com/

## 3) API schronień/POI używane bezpośrednio przez aplikację towarzyszącą

1. API bbox Refuges.info
   - https://www.refuges.info/api/bbox

2. API poligonów Refuges.info
   - https://www.refuges.info/api/polygones

3. Interpreter Overpass API
   - https://overpass-api.de/api/interpreter

## 4) Pobieranie danych tras

1. Segmenty tras BRouter
   - https://brouter.de/brouter/segments4/

## 5) Dane wysokości DEM

1. Kafelki Mapsforge DEM3
   - https://download.mapsforge.org/maps/dem/dem3

2. Mapzen Terrain Tiles / AWS skadi
   - https://s3.amazonaws.com/elevation-tiles-prod/skadi

## 6) Informacja o przejrzystości

- Te źródła są niezależne od GlanceMap.
- Dostępność i jakość plików, ciągłość działania usług oraz warunki prawne zależą od poszczególnych dostawców.
- Użytkownik pozostaje odpowiedzialny za prawa do dalszego rozpowszechniania plików pobranych z zewnątrz.
