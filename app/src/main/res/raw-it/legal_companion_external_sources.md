# Fonti esterne dell'app companion

Ultima revisione: 2026-03-20

Questo file elenca siti web e API di terzi usati dall'app companion per download e importazioni richiesti dall'utente.

## 1) Siti per scaricare mappe (aperti nel browser)

1. OpenAndroMaps
   - https://www.openandromaps.org/en/downloads

2. Alternativas Libres
   - https://alternativaslibres.org/en/downloads-mf.php

3. BBBike Extract
   - https://extract.bbbike.org/?format=mapsforge-osm.zip

4. Vector City
   - https://vector.city/

5. Freizeitkarte
   - https://www.freizeitkarte-osm.de/android/en/index.html

6. OpenHiking
   - https://www.openhiking.eu/en/downloads/mapsforge-maps

## 2) Scorciatoia sito GPX

1. VisuGPX
   - https://www.visugpx.com/

## 3) API rifugi/POI usate direttamente dall'app companion

1. API bbox di Refuges.info
   - https://www.refuges.info/api/bbox

2. API poligoni di Refuges.info
   - https://www.refuges.info/api/polygones

3. Interprete Overpass API
   - https://overpass-api.de/api/interpreter

## 4) Download dati percorsi

1. Segmenti percorsi BRouter
   - https://brouter.de/brouter/segments4/

## 5) Dati altimetrici DEM

1. Tessere DEM3 Mapsforge
   - https://download.mapsforge.org/maps/dem/dem3

2. Mapzen Terrain Tiles / AWS skadi
   - https://s3.amazonaws.com/elevation-tiles-prod/skadi

- Queste fonti sono esterne a GlanceMap.
